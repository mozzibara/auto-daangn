# 지역 중고거래 후보 정책: 바로구매 ≠ 타지역

## 근거

- [당근 공식 보도자료: 2026-03-03 바로구매 거래 범위 전국 확대](https://about.daangn.com/company/pr/archive/%EB%8B%B9%EA%B7%BC-%EB%B0%94%EB%A1%9C%EA%B5%AC%EB%A7%A4-%EA%B1%B0%EB%9E%98-%EB%B2%94%EC%9C%84-%EC%A0%84%EA%B5%AD-%ED%99%95%EB%8C%80/)
- [당근 공식 보도자료: 2025-09-18 바로구매 기능 도입](https://team.daangn.com/company/pr/archive/%EB%8B%B9%EA%B7%BC-%EC%A4%91%EA%B3%A0%EA%B1%B0%EB%9E%98-%EB%B0%94%EB%A1%9C%EA%B5%AC%EB%A7%A4-%EA%B8%B0%EB%8A%A5-%EB%8F%84%EC%9E%85/)

바로구매는 배송·안심결제 거래 옵션이며 지역 검색에 전국 상품이 혼합될 수
있다. 이는 '모든 바로구매 판매자가 다른 지역에 있다'는 뜻이 아니다.
같은 지역 바로구매 물품도 구매 후보에서 유지할 수 있어야 한다.

**2026-11-12 수정:** PR #47의 '바로구매/구매 CTA가 있으면 일괄 제외'는
지나친 정책이었으므로 철회한다. 바로구매는 *옵션*, 실제 지역은
*개별 상품의 위치 증거*, 직거래 가능 여부는 *판매자의 실제 의사*이다.

## 판정 원칙

| 현재 매물의 바로구매 표시 | 개별 상품 지역 증거 | 지역 직거래 후보 처리 |
| --- | --- | --- |
| 확인됨 | 같은 동 ID 또는 명시적 동일 시 | 유지, 단 직거래 가능 여부는 판매자 재확인 |
| 확인됨 | 명시적으로 다른 시 | 지역 직거래 후보에서 제외 (데이터 삭제는 아님) |
| 확인됨 | 불명확 | 지역 검증 보류, 원본 매물 유지 |
| 확인되지 않음 | 다른 시로 확인 | 지역 직거래 후보에서 제외 |
| 확인되지 않음 | 불명확 | 기존 검색 문맥 지역 및 독립 필터 검증은 그대로 수행 |
| 표시/화면 자체 불명확 | 모든 경우 | 검증 보류 |

단순히 구매 CTA `구매하기`만 관찰했을 때는 바로구매 기능으로 단정하지
않는다. 정확한 현재 매물 UI에 `바로구매` 라벨이 있어야 한다.

## 실제 코드 연결

1. `daangn_full_route_v4_14.RouteBodies`는 필터 적용 이후 UI와
   SHA로 상관 검증된 첫-party Route의 `buySellArticles[*].region`을
   기존 원본 `href` 배열 순서/신원 검증 후 메모리에서 읽는다.
2. `app_v5.listing_locality.classify_item_region`은
   검색문맥 `searchRegion/currentFilters`를 **절대** 개별 매물 위치로
   승격하지 않는다. 명시적 동일 region ID 또는 동일 municipality만
   동일 지역으로 분류한다. 다른 동 ID는 다른 '도시'의 증거가 아니다.
   명확한 별도 도시 값이 있을 때만 지역 밖으로 분류한다.
3. `daangn_detail_crosscheck_v4_20.pick_samples/audit_sample`은
   해당 관찰을 정확히 같은 Route 매물의 URL·가격 신원과 결합한다.
   상세 방문 횟수는 늘리지 않는다.
4. `daangn_state_controls_v4_23.project_v428_diagnosis`가
   상세 페이지가 그 매물과 정확히 일치할 때만 상수형 지역 판정을
   내보낸다. 원본 상품 위치·제목·판매자·주소·링크는 공개 아티팩트에
   추가되지 않는다.
5. `app_v5.buy_now_policy`와 `daangn_sale_filter_v4_31`은
   동일 지역 바로구매 후보를 판매 상태 검증으로 계속 진행시키고,
   먼 지역임이 명시적으로 검증된 매물만 지역 직거래 후보에서 막는다.
   지역 불명 바로구매는 `SALE_FILTER_HOLD_BUY_NOW_LOCALITY`로
   분류하며 **영구삭제하지 않는다**.

## 검증 범위와 한계

현재 `region` 필드는 Route 파서의 역사적 구조 분석에서 관찰됐지만,
실제 최신 UI 응답이 매물마다 그 필드를 제공하는지, ID와
municipality의 계층 의미가 일치하는지는 **라이브 재검증 전까지
확정되지 않았다.** 메타데이터가 없는 매물은 판정 보류한다.

같은 **도시**가 확인됐다고 해서 모두 가까운 거리에 있지는 않으며,
같은 도시임이 확인돼도 판매자가 직접 만날 의사가 있다는 보장은
없다. 추가로 판매자의 거래 가능 방식과 동네를 확인해야 한다.

이번 코드 변경은 기존 최대 9개 표본 상세 매물의 최종 후보 결정에
연결되는 단위 판정이다. 최초 Route가 650개까지 포함해도 전체
장바구니/추천 목록이 자동으로 완전히 지역 여과됐다는 뜻은 아니다.
실제 쇼핑용 매물 추천은 독립된 **검색 Route 지역·가격·카테고리·상태**
게이트 통과 후에만 가능하다.

**엄격한 `REGION_MISMATCH`는 계속 차단한다.** 바로구매 표기와
개별 매물 주소로 검색 Route 자체의 잘못된 지역을 우회하지 않는다.
새로운 지역 탐색, 상세 접속, 서버 상태 변경, OCI 원격 반영, 개인키
변경, 백업 타이머 실행은 없다.
