# 지역 매물 전용 정책: 바로구매 제외

## 근거

당근 공식 보도자료(2026-03-03):
https://about.daangn.com/company/pr/archive/%EB%8B%B9%EA%B7%BC-%EB%B0%94%EB%A1%9C%EA%B5%AC%EB%A7%A4-%EA%B1%B0%EB%9E%98-%EB%B2%94%EC%9C%84-%EC%A0%84%EA%B5%AD-%ED%99%95%EB%8C%80/

바로구매는 택배/안심결제 거래 방식이며, 검색 결과에 기존 동네 매물과
전국 바로구매 매물이 함께 나타날 수 있다. 검색 결과 노출 지역은
따라서 개별 매물의 판매 지역에 대한 직접적인 증거가 아니다.

## 정책

**지역 직접 거래 후보에서 바로구매를 제외한다.** 이번 적용 범위는
수집된 *정확한 매물*의 기존 v4.28 공개 상세 UI 관찰 및 v4.31
판매 가능 후보 판정이다. 서버 검색 지역 증거를 바꾸지 않는다.

- 현재 매물의 눈에 보이는 정확한 `바로구매`, `바로 구매` 라벨이나
  구매 CTA가 명시적으로 관찰되면 `EXCLUDED_BUY_NOW_OR_PURCHASE_CTA`.
  v4.31 `SALE_FILTER_BLOCK_BUY_NOW`로 제외하며 구매 링크 목록까지
  승격되지 않는다.
- 제대로 로드된 단일 현재 매물 화면에서 두 관찰 필드 모두 0이면
  `NO_BUY_NOW_UI_OBSERVED`. 이것은 *바로구매 표시가 관찰되지 않았다*
  는 좁은 의미다. 지역이 검증됐다는 뜻이 아니다.
- 페이지/매물 신원 불명확, 스캔 미완료, 필드 누락, 과거 버전 캡처는
  `UNVERIFIED_BUY_NOW_UI`: 자동 후보 통과 금지.
- 상세 페이지 본문에 있는 텍스트, 숨겨진 노드, 추천·관련 카드의 버튼은
  현재 매물의 바로구매 근거로 사용하지 않는다.
- 새 필드는 제한된 정수·고정 분류만 저장한다. 원본 위치, 제목, 판매자,
  링크, DOM 전문, 배달지, 주소는 공개 진단에 출력하지 않는다.

## 지역 증거는 독립

서버의 검색 기준 `searchRegion.id` 및
`currentFilters.regionId`가 OTHER로 반환되는 기존
`REGION_MISMATCH` 문제는 *전체 검색 문맥* 문제다.
바로구매 매물의 전국 노출이 이것의 직접 원인이라는 증거는 없다.
바로구매 제외는 그 불일치를 통과시키거나 예외 처리하지 않는다.

검색 필터/지역 증거가 확정되지 않으면 상세 방문을 시작하지 않는
기존 차단 규칙을 유지한다. 미검증 지역의 매물을 바로구매 여부만으로
지역 매물로 인정하지 않는다.

## 적용 경계

현재 v4.28/v4.31 경로는 최대 9개 소스 상세 매물에 대한 표본 검증이다.
그 이전 650개까지의 Route 목록 전체가 **이 코드만으로 배송 매물을 모두
배제했다고 주장할 수 없다.** 전체 검색 결과에서 직접 배제하려면
각 Route 행의 공식 바로구매 메타 필드를 독립적으로 검증하거나,
실제 표시된 카드의 정확한 식별 관계를 확인하는 별도 실험이 필요하다.

추가 네트워크 요청이나 사이트 우회 없이 현재 이미 방문한 매물만 검사하며,
전체 수집 경로에 적용됐다는 실증 판단은 실제 지역 선택이 정상 검증된
후 1회 승인형 라이브 실행과 그 결과를 확인해야 한다.
기존 OCI 키/DB/백업 및 비활성화 상태는 변경하지 않는다.
