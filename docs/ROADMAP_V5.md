# 당근 중고 매물 자동 탐색 — v5.0 공식 로드맵 복원안

기준: 2026-11-27. 원본 2026-11-26 통합 실행 계획(96개 ID, 13개 그룹)을 복원한다. 기준 main: `45e584bc2d236711ad61b30660caf8370c3ab810`. 이 표는 당시 증거 수준의 스냅샷이며 모든 코드/운영 기능 완료를 의미하지 않는다. main 병합 전에는 공식 채택 후보로 취급한다.

## 프로젝트 범위와 완료 기준

- STEP 1: 검증된 실제 매물 수집 → 암호화/서명 → 검증/반입 → SQLite 관찰 기록. 재수집·중복·실패 복구 증거 필요.
- STEP 2: 검색 프로필·가격 이력·신규 후보·목표가·Telegram 감시 및 피드백.
- STEP 3: 인증된 ChatGPT 연결·제품/이미지 분석·사용자 시나리오·운영 복구.
- GitHub Actions와 독립 CI 실행기는 보조 인프라이지 제품 완료 기준이 아니다. 범용 관리자 게이트웨이 확장 및 독립 CI 제품 개발은 이 로드맵에서 제외한다. 기존 분리 브랜치는 일괄 병합하지 않는다.
- 기존 라이브 승인, robots/접근 제한, 신선한 검색/서버/개별 매물 증거, 가격·카테고리·동일성·상태 검증을 유지한다. 검색 지역 선택 성공은 개별 소재지의 증명이 아니다. 재고 힌트는 직접 거래 상태가 아니다.
- 실제 운영 정책과 지역 허용목록·정확한 매물/사용자 정보·키·토큰은 비공개 유지. 연구용 지역 fixture를 운영 범위로 간주하지 않는다.
- 직접 확인된 SOLD 삭제 정책, 기존 키/DB 보존, 오프사이트 백업 비활성, 별도 프론트엔드/유료 LLM API 필수화 금지 유지.
- 기존 보호 규칙과 GitHub 필수 CI 유지. OCI 오프라인 테스트는 별도 증거이며 병합 권한을 부여하지 않는다.
